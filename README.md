# NebuloSonic

A compact **Web3 wallet portal experiment** focused on presenting account state and blockchain interactions through a simple product interface.

## Focus

- Wallet-first UX
- Account and balance presentation
- Web3 interaction patterns
- Mobile-friendly product design
- Lightweight experimentation

## Status

NebuloSonic is an experimental Web3 product workspace. Features and integrations may evolve as the underlying wallet and chain architecture changes.
